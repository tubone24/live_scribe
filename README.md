# Live Scribe

iPhone の Safari で動く、商談向けのリアルタイム文字起こしページです。

- ブラウザ標準の音声認識（Web Speech API, `ja-JP`）で文字起こしし、画面に流し続けます
- 音声は保存しません。テキストはその端末のブラウザ内（localStorage）にのみ保存します
- 「送る」で前回送信以降の分だけを .txt ファイルとしてダウンロードします（クリップボードは使いません）
- 出力は Claude が読みやすい形式です：データを XML タグ（context / notes / important / transcript）で区切り、末尾に指示（instructions）を付けます。指示と商談のコンテキストは設定で編集できます
- 話者分離はしません。★ で重要マーク、📝 で手入力メモ
- 蛍光ペン：要望・課題・宿題・数字/期限の言い回しを含む句にマーカーを引きます（ルールベース）
- AI 要約（実験）：設定でオンにすると、端末内の小型 LLM（transformers.js + WebGPU。既定は LFM2 350M、ほかに Qwen3 0.6B / TinySwallow 1.5B）で、話した内容を数分ごとに箇条書きにして画面下に表示します。モデルは初回のみ Hugging Face からダウンロードしてブラウザにキャッシュし、文字起こしは端末の外に出ません。iOS 26 以降の Safari が必要です
- 録音中は Wake Lock API で画面を点けたままにします

## 使い方

1. iPhone の Safari で開く（ホーム画面に追加すると音声認識が動かない場合があります）
2. 設定 > アプリ > Safari > マイク を許可、Siri（音声入力）を有効にしておく
3. 「録音開始」→ 適宜「送る」→「ファイル」アプリ > ダウンロード からファイルを開き、共有で Slack に送る
